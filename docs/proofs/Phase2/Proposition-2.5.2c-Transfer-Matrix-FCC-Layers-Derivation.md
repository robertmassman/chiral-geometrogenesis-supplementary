## 7. (111) Layer Decomposition of the FCC Lattice

**Status:** 🔶 NOVEL application of ESTABLISHED crystallography

### 7.1 The [111] Direction in the FCC Lattice

The FCC lattice is generated by the primitive vectors (Prop 2.5.2b SS7.5):

$$\mathbf{a}_1 = \frac{a}{2}(0,1,1), \quad \mathbf{a}_2 = \frac{a}{2}(1,0,1), \quad \mathbf{a}_3 = \frac{a}{2}(1,1,0) \tag{7.1}$$

where $a$ is the conventional cubic cell edge length. The body diagonal of the conventional cubic cell defines the [111] direction:

$$\hat{\mathbf{d}} = \frac{1}{\sqrt{3}}(1,1,1) \tag{7.2}$$

The perpendicular planes to $\hat{\mathbf{d}}$ passing through FCC lattice sites define the (111) layers. The projection of an FCC site $\mathbf{r} = n_1\mathbf{a}_1 + n_2\mathbf{a}_2 + n_3\mathbf{a}_3$ onto $\hat{\mathbf{d}}$ is computed via:

$$\mathbf{a}_1 \cdot \hat{\mathbf{d}} = \frac{a}{2\sqrt{3}}(0+1+1) = \frac{a}{\sqrt{3}}, \quad \mathbf{a}_2 \cdot \hat{\mathbf{d}} = \frac{a}{\sqrt{3}}, \quad \mathbf{a}_3 \cdot \hat{\mathbf{d}} = \frac{a}{\sqrt{3}} \tag{7.3}$$

Therefore:

$$\mathbf{r}\cdot\hat{\mathbf{d}} = \frac{a}{\sqrt{3}}(n_1+n_2+n_3) \tag{7.4}$$

The (111) layers are labeled by the integer $s = n_1 + n_2 + n_3$, with inter-layer spacing:

$$d_{111} = \frac{a}{\sqrt{3}} \tag{7.5}$$

### 7.2 A$_2$ Lattice Structure of Each Layer

Within a given (111) layer (fixed $s = n_1 + n_2 + n_3$), the sites form a two-dimensional triangular lattice. To see this, introduce in-plane coordinates. For the layer $s = 0$, parametrize by $(n_1, n_2)$ with $n_3 = -n_1 - n_2$:

$$\mathbf{r} = n_1(\mathbf{a}_1 - \mathbf{a}_3) + n_2(\mathbf{a}_2 - \mathbf{a}_3) \tag{7.6}$$

The in-plane primitive vectors are:

$$\mathbf{e}_1 = \mathbf{a}_1 - \mathbf{a}_3 = \frac{a}{2}(-1,0,1), \quad \mathbf{e}_2 = \mathbf{a}_2 - \mathbf{a}_3 = \frac{a}{2}(0,-1,1) \tag{7.7}$$

These satisfy $|\mathbf{e}_1| = |\mathbf{e}_2| = a/\sqrt{2}$ and $\mathbf{e}_1 \cdot \mathbf{e}_2 = a^2/4$, giving angle $\cos\theta = 1/2$, i.e., $\theta = 60°$. This is precisely the $A_2$ (triangular) lattice with lattice constant $a/\sqrt{2}$.

**Stacking sequence.** The FCC lattice has an ABCABC stacking along [111]. Three consecutive layers at $s$, $s+1$, $s+2$ are displaced laterally by:

$$\boldsymbol{\delta}_{AB} = \mathbf{a}_3 = \frac{a}{2}(1,1,0), \qquad \boldsymbol{\delta}_{BC} = \mathbf{a}_1 = \frac{a}{2}(0,1,1) \tag{7.8}$$

projected into the (111) plane. The sequence repeats with period 3: the layer at $s + 3$ is directly above the layer at $s$.

### 7.3 Inter-Layer Geometry

Between adjacent (111) layers (say layers A at $s = 0$ and B at $s = 1$), the tetrahedral-octahedral honeycomb creates a specific arrangement of polyhedra.

**Inter-layer slab structure.** Consider the slab between layers $s$ and $s+1$. The FCC sites in these two layers, together with the nearest-neighbor edges connecting them, define a 3D slab. Within this slab:

- **Upward-pointing tetrahedra** ($T_+$): Each has 3 vertices in layer $s$ and 1 vertex in layer $s+1$. There are $N_s$ such tetrahedra per slab (one per $A_2$ unit cell in layer $s$).

- **Downward-pointing tetrahedra** ($T_-$): Each has 1 vertex in layer $s$ and 3 vertices in layer $s+1$. There are $N_s$ such tetrahedra per slab.

- **Octahedra**: Each has 3 vertices in layer $s$ and 3 vertices in layer $s+1$. There are $N_s$ octahedra per slab.

Here $N_s$ denotes the number of FCC sites per (111) layer.

**Per-slab combinatorics** (slab between layers $s$ and $s+1$):

| Object | Count per slab | Notes |
|--------|---------------|-------|
| Vertices (in slab) | $2N_s$ | $N_s$ per layer |
| Intra-layer edges | $6N_s$ | 3 per vertex within each layer, shared |
| Inter-layer edges | $3N_s$ | Each vertex in layer $s$ connects to 3 vertices in layer $s+1$ |
| Total edges in slab | $6N_s$ | Combining intra and inter, accounting for sharing |
| Triangular faces (in slab) | $8N_s$ | From $2N_s$ tetrahedra ($4 \times 2N_s$ faces) + $N_s$ octahedra ($8N_s$ faces), divided by sharing factor 2 |
| 3-cells | $3N_s$ | $2N_s$ tet + $N_s$ oct |

**Verification of inter-layer edge count.** Each FCC site has 12 nearest neighbors. Of these, 6 lie in the same (111) layer (forming the $A_2$ lattice) and 6 lie in adjacent layers (3 in the layer above and 3 in the layer below). The 3 inter-layer edges from each site in layer $s$ to layer $s+1$ give $3N_s$ inter-layer edges per slab (each edge counted once, since the other endpoint is in layer $s+1$). The intra-layer edges within the slab's two layers are: each layer has $N_s$ sites with 6 neighbors in the same layer, giving $6N_s/2 = 3N_s$ edges per layer, so $6N_s$ total intra-layer edges across both layers.

**Verification of face count via cell-face incidence.** Per slab:
- $2N_s$ tetrahedra, each with 4 faces: $8N_s$ cell-face incidences from tetrahedra
- $N_s$ octahedra, each with 8 faces: $8N_s$ cell-face incidences from octahedra
- Total incidences: $16N_s$
- Each face shared by 2 cells: $16N_s / 2 = 8N_s$ distinct faces. $\checkmark$

**Euler characteristic check for a single slab** (open boundary conditions along [111]):
$$\chi_\text{slab}^{(2)} = V_\text{slab} - E_\text{slab} + F_\text{slab} = 2N_s - (6N_s + 3N_s) + 8N_s = 2N_s - 9N_s + 8N_s = N_s \tag{7.9a}$$

Note: this uses the total edges in the slab including both intra-layer ($6N_s$) and inter-layer ($3N_s$), giving $E_\text{slab} = 9N_s$ for a slab with open boundary conditions. For the periodic lattice, the per-layer contribution to $\chi_2$ is $3N_s$ (not $N_s$) because the periodic identification changes the combinatorics --- each layer's intra-layer edges are shared between two slabs.

### 7.4 Combinatorics Per Layer

For the full periodic lattice with $L$ layers (periodic boundary conditions along [111]) and $N_s$ sites per layer:

$$N = N_s \times L \tag{7.9}$$

The total combinatorics are:

$$V = N_s L, \quad E = 6N_s L, \quad F = 8N_s L, \quad C_3 = 3N_s L \tag{7.10}$$

These are consistent with the Prop 2.5.2b values $V = N$, $E = 6N$, $F = 8N$, $C_3 = 3N$ upon substituting $N = N_s L$.

**Per-layer contribution.** Dividing by the number of layers $L$:

$$V/L = N_s, \quad E/L = 6N_s, \quad F/L = 8N_s \tag{7.11}$$

The 2-skeleton Euler characteristic per layer is:

$$\chi_2/L = N_s - 6N_s + 8N_s = 3N_s \tag{7.12}$$

This is the per-layer contribution to the total $\chi_2 = 3N = 3N_sL$.

### 7.5 Explicit Construction for Small Lattices

**$N_s = 1$, $L = 1$:** A single primitive cell with periodic boundary conditions in all three directions. This is the minimal FCC lattice on the 3-torus $T^3$:
- $V = 1$, $E = 6$, $F = 8$, $C_3 = 3$
- $\chi_2 = 1 - 6 + 8 = 3$
- $Z = \sum_R d_R^3 a_R^8$
- Transfer matrix: $\hat{T}$ is $1 \times 1$ in the layer direction (trivially: $Z = \text{Tr}(\hat{T}^1) = \sum_R \lambda_R$)

**$N_s = 1$, $L = 3$:** A one-cell-wide FCC column with 3 layers (minimal non-trivial transfer matrix geometry):
- $V = 3$, $E = 18$, $F = 24$, $C_3 = 9$
- $\chi_2 = 3 - 18 + 24 = 9 = 3 \times 3$
- $Z = \sum_R d_R^9 a_R^{24} = \sum_R (d_R^3 a_R^8)^3 = \text{Tr}(\hat{T}^3)$
- Eigenvalue: $\lambda_R = d_R^3 a_R^8$ (confirmed by comparison with $N_s = 1$)

**$N_s = 4$, $L = 3$:** A $2 \times 2$ triangular cross-section with 3 layers:
- $V = 12$, $E = 72$, $F = 96$, $C_3 = 36$
- $\chi_2 = 12 - 72 + 96 = 36 = 3 \times 12$
- $Z = \sum_R d_R^{36} a_R^{96} = \sum_R (d_R^{12} a_R^{32})^3 = \text{Tr}(\hat{T}^3)$
- Eigenvalue: $\lambda_R = d_R^{12} a_R^{32} = d_R^{3 \times 4} a_R^{8 \times 4} = (d_R^3 a_R^8)^{N_s}$ with $N_s = 4$ (as expected)

## 8. Transfer Matrix Hilbert Space

**Status:** 🔶 NOVEL

### 8.1 States on a Single Layer

The transfer matrix formalism requires defining a Hilbert space of states on a single (111) layer. In lattice gauge theory, the states on a spatial slice are gauge-invariant functionals of the spatial link variables.

After the character expansion of Prop 2.5.2b, the partition function $Z_\text{FCC} = \sum_R d_R^{3N} a_R^{8N}$ is expressed as a single sum over representation labels. The key structural insight from Prop 2.5.2b (Theorem 10.8.1 and Corollary 10.10.2) is:

> **The global label constraint forces all $8N$ face labels across the entire lattice to take the same value $R$.**

This constraint applies both within each (111) layer and across layers. Within a single layer, the constraint is mediated by the face-sharing graph restricted to that layer.

### 8.2 The Representation Basis

The gauge-invariant Hilbert space for the transfer matrix is spanned by states labeled by SU(3) irreducible representations:

$$\mathcal{H} = \bigoplus_{R \in \widehat{SU(3)}} \mathbb{C}|R\rangle \tag{8.1}$$

Each basis state $|R\rangle$ corresponds to the configuration in which ALL faces within the (111) layer carry representation label $R$. This is a uniform state --- all spatial face labels take the same value.

**Physical interpretation.** The state $|R\rangle$ represents a layer in which the gauge field is in the "sector" corresponding to representation $R$. The trivial representation $|\mathbf{1}\rangle$ is the strong-coupling vacuum; excited states $|\mathbf{3}\rangle$, $|\mathbf{8}\rangle$, etc., carry color flux.

### 8.3 Why the Hilbert Space Is So Simple

The dramatic simplification of the Hilbert space (from an infinite-dimensional functional space to a countable basis $\{|R\rangle\}$) arises from three facts:

**(i) Within-cell constraint.** From Prop 2.5.2b SS10.5, the character expansion and Haar integration within each cell (whose boundary is $S^2$ with $\chi = 2$) forces all face labels of that cell to agree. This is the standard 2D lattice gauge theory result for a triangulation of $S^2$.

**(ii) Face-sharing propagation.** From Prop 2.5.2b Lemma 7.7.2, the face-sharing graph $\mathcal{G}_\text{face}$ is connected. Adjacent cells share a triangular face, which carries a single representation label visible to both cells. Combined with (i), this forces adjacent cells to carry the same label.

**(iii) Connectivity within a layer.** The restriction of $\mathcal{G}_\text{face}$ to cells within a single (111) slab is connected. Each slab contains $3N_s$ cells ($2N_s$ tetrahedra + $N_s$ octahedra), and every cell shares at least one face with another cell in the same slab. Therefore, the within-layer constraint propagation forces all intra-layer face labels to agree.

**Result.** The gauge-invariant Hilbert space on a single (111) layer is spanned by uniform states $|R\rangle$, one for each $R \in \widehat{SU(3)}$. Non-uniform configurations (different labels on different spatial faces) are projected out by the Haar integrations over spatial link variables.

### 8.4 Dimension Counting

The Hilbert space $\mathcal{H}$ is countably infinite-dimensional (one basis vector per SU(3) irrep). The irreducible representations of SU(3) are labeled by pairs of non-negative integers $(p,q)$ (Dynkin labels), with dimension:

$$d_{(p,q)} = \frac{1}{2}(p+1)(q+1)(p+q+2) \tag{8.2}$$

At any finite coupling $\beta$, the partition function converges because $a_R(\beta) \to 0$ sufficiently fast as $d_R \to \infty$ (Prop 0.0.38 SS7). In practice, for strong coupling ($\beta \lesssim 5$), the first few representations dominate and the effective dimension is small.

## 9. Transfer Matrix Construction

**Status:** 🔶 NOVEL

### 9.1 Definition

The transfer matrix $\hat{T}$ acts on the Hilbert space $\mathcal{H}$ by propagating states from layer $n$ to layer $n+1$ along the [111] direction. Its matrix elements are defined by:

$$\langle R'| \hat{T} |R\rangle = \text{(amplitude for a layer in state } |R\rangle \text{ to evolve to state } |R'\rangle \text{)} \tag{9.1}$$

Concretely, $\hat{T}$ encodes the integration over all inter-layer link variables (the temporal edges connecting layer $n$ to layer $n+1$) and the Boltzmann weights of all faces in the inter-layer slab.

The partition function on the periodic lattice with $L$ layers is:

$$Z_\text{FCC}(\beta, N_s, L) = \text{Tr}(\hat{T}^L) = \sum_R \lambda_R^L \tag{9.2}$$

where the trace is over $\mathcal{H}$ and $\{\lambda_R\}$ are the eigenvalues of $\hat{T}$.

### 9.2 Diagonality

**Theorem 9.2.1 (Diagonal transfer matrix).** The transfer matrix $\hat{T}$ is diagonal in the representation basis:

$$\langle R'| \hat{T} |R\rangle = \lambda_R \, \delta_{R,R'} \tag{9.3}$$

*Proof.* The input state $|R\rangle$ specifies that all spatial faces in layer $n$ carry label $R$. The output state $|R'\rangle$ specifies that all spatial faces in layer $n+1$ carry label $R'$. The inter-layer slab contains $3N_s$ cells ($2N_s$ tetrahedra + $N_s$ octahedra), and its faces include:

1. Intra-layer faces in layer $n$ (already labeled $R$)
2. Intra-layer faces in layer $n+1$ (to be labeled $R'$)
3. Inter-layer faces connecting layers $n$ and $n+1$

The inter-layer faces are shared between the cells of the slab. By the within-cell constraint (Prop 2.5.2b, Theorem 10.5.1), all face labels within each cell must agree. Since the face-sharing graph within the slab is connected (SS8.3), all face labels in the slab --- including the inter-layer faces --- must be equal.

But the intra-layer faces in layer $n$ are already labeled $R$ and the intra-layer faces in layer $n+1$ are labeled $R'$. These are both connected to the inter-layer faces through shared cells. Therefore the constraint forces $R = R'$.

Hence $\langle R'| \hat{T} |R\rangle = 0$ unless $R = R'$, and $\hat{T}$ is diagonal. $\square$

**Remark 9.2.2.** The diagonality of $\hat{T}$ is a consequence of the global label constraint from Prop 2.5.2b. In standard lattice gauge theory on the hypercubic lattice, the transfer matrix is NOT diagonal --- the representation labels can vary across spatial plaquettes. The simplification here is specific to the FCC geometry, where the face-sharing constraints are so strong that the entire spatial configuration is determined by a single label.

### 9.3 Eigenvalue Computation

**Theorem 9.3.1 (Transfer matrix eigenvalues).** The eigenvalues of the FCC transfer matrix are:

$$\boxed{\lambda_R(\beta, N_s) = d_R^{3N_s} \, [a_R(\beta)]^{8N_s}} \tag{9.4}$$

for each $R \in \widehat{SU(3)}$.

*Proof.* From Prop 2.5.2b (Eq. 10.16), the partition function on the periodic FCC lattice with $N = N_s L$ sites is:

$$Z_\text{FCC}(\beta, N_s L) = \sum_R d_R^{3N_s L} \, [a_R(\beta)]^{8N_s L} \tag{9.5}$$

Factoring the exponents:

$$Z_\text{FCC} = \sum_R \left(d_R^{3N_s} \, a_R^{8N_s}\right)^L \tag{9.6}$$

Comparing with the trace formula (9.2):

$$\text{Tr}(\hat{T}^L) = \sum_R \lambda_R^L \tag{9.7}$$

Since both expressions hold for all $L \geq 1$ and the representation labels $R$ are in bijection, we identify:

$$\lambda_R = d_R^{3N_s} \, a_R^{8N_s} \tag{9.8}$$

This identification is unique because the $\lambda_R$ are non-negative and the representations are distinguishable by their dimensions. $\square$

**Properties of the eigenvalues:**

1. **Positivity.** $\lambda_R > 0$ for all $R$ and all $\beta > 0$, since $d_R > 0$ (dimension of an irrep is positive) and $a_R(\beta) > 0$ (Prop 0.0.38, heat kernel positivity, Appendix B.5 of Prop 2.5.2b Derivation). This is essential for reflection positivity of the transfer matrix.

2. **Exactness.** The eigenvalues (9.4) are EXACT for all $\beta$ --- no strong-coupling or weak-coupling approximation is involved. They follow directly from the exact partition function formula.

3. **Extensivity.** The eigenvalues grow exponentially with $N_s$ (the spatial volume). This is the expected behavior for a transfer matrix in statistical mechanics: the eigenvalues scale as $e^{-N_s f_R}$ where $f_R$ is the free energy density associated with representation $R$.

### 9.4 Explicit Eigenvalues for Leading Representations

For $N_s = 1$ (minimal spatial volume), the eigenvalues are:

| $R$ | $(p,q)$ | $d_R$ | $d_R^3$ | $\lambda_R = d_R^3 a_R^8$ | $\lambda_R / \lambda_\mathbf{1}$ |
|-----|---------|-------|---------|--------------------------|-------------------------------|
| $\mathbf{1}$ | $(0,0)$ | 1 | 1 | $a_\mathbf{1}^8$ | 1 |
| $\mathbf{3}$, $\bar{\mathbf{3}}$ | $(1,0)$, $(0,1)$ | 3 | 27 | $27 \, a_\mathbf{3}^8$ | $27 \, u_\mathbf{3}^8$ |
| $\mathbf{6}$, $\bar{\mathbf{6}}$ | $(2,0)$, $(0,2)$ | 6 | 216 | $216 \, a_\mathbf{6}^8$ | $216 \, u_\mathbf{6}^8$ |
| $\mathbf{8}$ | $(1,1)$ | 8 | 512 | $512 \, a_\mathbf{8}^8$ | $512 \, u_\mathbf{8}^8$ |
| $\mathbf{10}$, $\overline{\mathbf{10}}$ | $(3,0)$, $(0,3)$ | 10 | 1000 | $1000 \, a_{\mathbf{10}}^8$ | $1000 \, u_{\mathbf{10}}^8$ |
| $\mathbf{15}$ | $(2,1)$ | 15 | 3375 | $3375 \, a_{\mathbf{15}}^8$ | $3375 \, u_{\mathbf{15}}^8$ |
| $\mathbf{15}'$ | $(4,0)$ | 15 | 3375 | $3375 \, a_{\mathbf{15}'}^8$ | $3375 \, u_{\mathbf{15}'}^8$ |
| $\mathbf{27}$ | $(2,2)$ | 27 | 19683 | $19683 \, a_{\mathbf{27}}^8$ | $19683 \, u_{\mathbf{27}}^8$ |

Here $u_R(\beta) = a_R(\beta)/a_\mathbf{1}(\beta)$ is the reduced heat kernel coefficient (Prop 0.0.38a SS2).

For general $N_s$, each entry scales as the $N_s$-th power:

$$\lambda_R(N_s) = [\lambda_R(N_s=1)]^{N_s} \tag{9.9}$$

### 9.5 Comparison with Single-Stella Transfer Matrix

The single-stella (K$_4$) transfer matrix eigenvalues from Prop 0.0.38a (Eq. 4.3) are:

$$t_R^{(K_4)} = d_R^4 \, a_R^{10} \tag{9.10}$$

with $\chi = 4$ per time step and $F = 10$ plaquettes per time step.

The FCC transfer matrix eigenvalues (per layer, $N_s = 1$) are:

$$\lambda_R^{(\text{FCC})} = d_R^3 \, a_R^8 \tag{9.11}$$

with $\chi_2/L = 3$ per layer and $F/L = 8$ faces per layer.

| Quantity | Single K$_4$ | FCC ($N_s = 1$) |
|----------|-------------|-----------------|
| $d_R$ exponent | 4 | 3 |
| $a_R$ exponent | 10 | 8 |
| Ratio $a_R / d_R$ exponents | 10/4 = 2.5 | 8/3 $\approx$ 2.67 |

The FCC has a slightly higher ratio of face-to-Euler contributions per layer, reflecting the denser packing of the assembled lattice compared to the isolated K$_4$ cylinder.

## 10. Mass Gap

**Status:** 🔶 NOVEL

### 10.1 Definition

The mass gap of the FCC transfer matrix is defined as the logarithmic ratio of the ground-state eigenvalue to the first excited eigenvalue:

$$m_\text{gap}(\beta, N_s) = -\ln\!\left(\frac{\lambda_\text{first excited}}{\lambda_\text{ground}}\right) \tag{10.1}$$

At strong coupling ($\beta \ll 1$), the trivial representation has the largest eigenvalue ($\lambda_\mathbf{1}$ is the ground state), and the fundamental representation $\mathbf{3}$ (or $\bar{\mathbf{3}}$) is the first excited state:

$$\boxed{m_\text{gap}(\beta, N_s) = \ln\!\left(\frac{\lambda_\mathbf{1}}{\lambda_\mathbf{3}}\right) = -3N_s \ln 3 - 8N_s \ln u_\mathbf{3}(\beta)} \tag{10.2}$$

where $u_\mathbf{3}(\beta) = a_\mathbf{3}(\beta)/a_\mathbf{1}(\beta)$.

*Derivation.* Using $\lambda_R = d_R^{3N_s} a_R^{8N_s}$:

$$\ln\!\left(\frac{\lambda_\mathbf{1}}{\lambda_\mathbf{3}}\right) = \ln\!\left(\frac{d_\mathbf{1}^{3N_s} a_\mathbf{1}^{8N_s}}{d_\mathbf{3}^{3N_s} a_\mathbf{3}^{8N_s}}\right) = 3N_s \ln\!\left(\frac{d_\mathbf{1}}{d_\mathbf{3}}\right) + 8N_s \ln\!\left(\frac{a_\mathbf{1}}{a_\mathbf{3}}\right)$$

$$= -3N_s \ln 3 - 8N_s \ln u_\mathbf{3}(\beta) \tag{10.3}$$

Since $u_\mathbf{3}(\beta) < 1$ for all finite $\beta$, we have $-\ln u_\mathbf{3} > 0$. The sign of $m_\text{gap}$ is then determined by whether $-8N_s \ln u_\mathbf{3}$ exceeds $3N_s \ln 3$. $\square$

### 10.2 Explicit Formula

The mass gap has a clean closed form:

$$m_\text{gap}(\beta, N_s) = N_s \left(-3\ln 3 - 8\ln u_\mathbf{3}(\beta)\right) = N_s \left(8\ln\!\frac{1}{u_\mathbf{3}(\beta)} - 3\ln 3\right) \tag{10.4}$$

This is manifestly extensive: $m_\text{gap} \propto N_s$.

### 10.3 Strong Coupling Limit

At strong coupling ($\beta \ll 1$), the leading-order heat kernel coefficient for the fundamental representation is (Prop 0.0.38 SS5.1):

$$u_\mathbf{3}(\beta) \approx \frac{\beta}{18} + O(\beta^3) \tag{10.5}$$

Substituting into (10.4):

$$m_\text{gap}(\beta, N_s) \approx N_s\!\left(8\ln\!\frac{18}{\beta} - 3\ln 3\right) \tag{10.6}$$

**Numerical estimates at $N_s = 1$:**

| $\beta$ | $u_\mathbf{3}$ | $m_\text{gap}$ | Phase |
|---------|--------|-------------|-------|
| 0.1 | 0.0056 | 38.3 | Deeply gapped |
| 0.5 | 0.0289 | 25.1 | Strongly gapped |
| 1.0 | 0.0601 | 19.2 | Gapped |
| 2.0 | 0.1286 | 13.2 | Gapped |
| 4.0 | 0.2796 | 6.9 | Gapped |
| 6.0 | 0.4225 | 3.6 | Weakly gapped |
| 8.0 | 0.5358 | 1.7 | Near critical |
| 10.0 | 0.6182 | 0.5 | Near gap closing |
| 12.0 | 0.6795 | $-$0.3 | Gap closed |

At $\beta = 1$ and $N_s = 1$: $m_\text{gap} \approx 8 \times \ln(18) - 3\ln 3 \approx 8 \times 2.890 - 3.296 \approx 19.8$. (The table entries use numerically computed $u_\mathbf{3}$ values from the Weyl integral rather than the leading-order approximation.)

### 10.4 Intensive Mass Gap

**Definition 10.4.1.** The intensive mass gap is the mass gap per spatial unit cell:

$$\boxed{\mu(\beta) \equiv \frac{m_\text{gap}(\beta, N_s)}{N_s} = -3\ln 3 - 8\ln u_\mathbf{3}(\beta)} \tag{10.7}$$

This is independent of $N_s$, which is a non-trivial property: the mass gap scales linearly with spatial volume, and the coefficient is well-defined in the thermodynamic limit $N_s \to \infty$.

**Properties of $\mu(\beta)$:**

1. **$\beta \to 0$ (strong coupling):** $\mu \to +\infty$ (logarithmically). The system is deeply gapped.

2. **Monotonicity:** $\mu(\beta)$ is a decreasing function of $\beta$, since $u_\mathbf{3}(\beta)$ is an increasing function of $\beta$ (higher representations are less suppressed at weaker coupling).

3. **$N_s$-independence:** The intensive gap $\mu$ depends only on the coupling $\beta$, not on the spatial volume. This means the mass gap SURVIVES the thermodynamic limit $N_s \to \infty$ (for $\beta < \beta_c$).

### 10.5 Critical Coupling Analysis

The mass gap vanishes when $\mu(\beta_c) = 0$:

$$-3\ln 3 - 8\ln u_\mathbf{3}(\beta_c) = 0 \tag{10.8}$$

$$\ln u_\mathbf{3}(\beta_c) = -\frac{3}{8}\ln 3 \tag{10.9}$$

$$\boxed{u_\mathbf{3}(\beta_c) = 3^{-3/8} \approx 0.6623} \tag{10.10}$$

**Verification of the critical condition.** At $u_\mathbf{3} = 3^{-3/8}$:

$$\mu = -3\ln 3 - 8 \times \left(-\frac{3}{8}\ln 3\right) = -3\ln 3 + 3\ln 3 = 0 \quad \checkmark$$

**Physical interpretation:**

- For $\beta < \beta_c$ (i.e., $u_\mathbf{3} < 3^{-3/8}$): $\mu > 0$, the trivial representation dominates, and the system is in the **confined phase**. The mass gap is positive.

- At $\beta = \beta_c$: $\mu = 0$, the fundamental representation eigenvalue catches up to the trivial representation eigenvalue. This is the **deconfinement transition**.

- For $\beta > \beta_c$ (i.e., $u_\mathbf{3} > 3^{-3/8}$): $\mu < 0$, meaning $\lambda_\mathbf{3} > \lambda_\mathbf{1}$. The "ground state" shifts from $|\mathbf{1}\rangle$ to $|\mathbf{3}\rangle$ (or more precisely, to the representation $R^*$ that maximizes $d_R^3 a_R^8$). The system enters the **deconfined phase**.

**Numerical estimate of $\beta_c$.** From the numerically computed $u_\mathbf{3}(\beta)$ (via the Weyl integral), solving $u_\mathbf{3}(\beta_c) = 3^{-3/8} \approx 0.6623$ gives:

$$\beta_c^{(\text{FCC})} \approx 11.5 \tag{10.11}$$

(The precise value depends on the numerical evaluation of the heat kernel coefficients.)

### 10.6 Comparison with Single-Stella Mass Gap

The single K$_4$ transfer matrix mass gap from Prop 0.0.38a (Eq. 4.4) is:

$$m_\text{gap}^{(K_4)} = -4\ln 3 - 10\ln u_\mathbf{3}(\beta) \tag{10.12}$$

The FCC intensive mass gap (10.7) is:

$$\mu_\text{FCC} = -3\ln 3 - 8\ln u_\mathbf{3}(\beta) \tag{10.13}$$

**Comparison of coefficients:**

| Quantity | K$_4$ transfer matrix | FCC intensive gap |
|----------|---------------------|-------------------|
| $\ln d_\mathbf{3}$ coefficient | $-4$ | $-3$ |
| $\ln u_\mathbf{3}$ coefficient | $-10$ | $-8$ |
| Critical $u_\mathbf{3}$ | $3^{-2/5} \approx 0.644$ | $3^{-3/8} \approx 0.662$ |
| Critical $\beta$ | $\approx 11.1$ | $\approx 11.5$ |
| Gap at $\beta = 1$ | $\approx 24.5$ | $\approx 19.8$ |

The single K$_4$ has a LARGER gap per unit than the FCC intensive gap. This is because:

1. The K$_4$ cylinder has more plaquettes per time step (10 vs 8 per layer) relative to its Euler characteristic (4 vs 3 per layer), giving stronger suppression of non-trivial representations.

2. The FCC assembly shares faces between cells, reducing the effective number of independent Boltzmann weights per cell. This changes the entropy-energy balance.

3. The critical coupling is slightly higher for the FCC ($\beta_c \approx 11.5$ vs $\approx 11.1$), meaning the FCC stays confined over a wider range of coupling.

The key physical point is that both systems are gapped at strong coupling, and the FCC gap --- though different from the K$_4$ gap --- is well-defined and extensive.

## 11. Spectral Analysis

**Status:** 🔶 NOVEL

### 11.1 Full Spectrum

The transfer matrix eigenvalue for an arbitrary SU(3) representation labeled by Dynkin indices $(p,q)$ is:

$$\lambda_{(p,q)}(\beta, N_s) = d_{(p,q)}^{3N_s} \, [a_{(p,q)}(\beta)]^{8N_s} \tag{11.1}$$

where the dimension formula is:

$$d_{(p,q)} = \frac{1}{2}(p+1)(q+1)(p+q+2) \tag{11.2}$$

The excitation energy (relative to the ground state $R = \mathbf{1}$) is:

$$E_{(p,q)}(\beta, N_s) = -\ln\!\left(\frac{\lambda_{(p,q)}}{\lambda_\mathbf{1}}\right) = -3N_s \ln d_{(p,q)} - 8N_s \ln u_{(p,q)}(\beta) \tag{11.3}$$

The intensive excitation energy is:

$$\epsilon_{(p,q)}(\beta) = \frac{E_{(p,q)}}{N_s} = -3\ln d_{(p,q)} - 8\ln u_{(p,q)}(\beta) \tag{11.4}$$

### 11.2 Casimir Ordering and N-ality Structure

The SU(3) representations are characterized by their quadratic Casimir eigenvalue $C_2(R)$ and $N$-ality (triality) $k = (p - q) \mod 3$:

| $R$ | $(p,q)$ | $d_R$ | $C_2(R)$ | $N$-ality | Leading $u_R$ |
|-----|---------|-------|----------|-----------|---------------|
| $\mathbf{1}$ | $(0,0)$ | 1 | 0 | 0 | 1 |
| $\mathbf{3}$ | $(1,0)$ | 3 | 4/3 | 1 | $\beta/18$ |
| $\bar{\mathbf{3}}$ | $(0,1)$ | 3 | 4/3 | 2 | $\beta/18$ |
| $\mathbf{6}$ | $(2,0)$ | 6 | 10/3 | 2 | $\sim\beta^2$ |
| $\bar{\mathbf{6}}$ | $(0,2)$ | 6 | 10/3 | 1 | $\sim\beta^2$ |
| $\mathbf{8}$ | $(1,1)$ | 8 | 3 | 0 | $\sim\beta^2$ |
| $\mathbf{10}$ | $(3,0)$ | 10 | 6 | 0 | $\sim\beta^3$ |
| $\mathbf{15}$ | $(2,1)$ | 15 | 16/3 | 1 | $\sim\beta^3$ |
| $\mathbf{27}$ | $(2,2)$ | 27 | 8 | 0 | $\sim\beta^4$ |

At strong coupling, $u_R(\beta)$ scales as $\beta^{n(R)}$ where $n(R)$ is related to the minimum number of fundamental plaquettes needed to construct $R$ from tensor products. The Casimir determines the rate of suppression.

### 11.3 Eigenvalue Ordering at Strong Coupling

At strong coupling ($\beta \ll 1$), the heat kernel coefficients satisfy the hierarchy $u_\mathbf{3} \gg u_\mathbf{8} \gg u_\mathbf{10} \gg \cdots$ (higher representations are more strongly suppressed). The eigenvalue ordering is determined by the balance between $d_R^{3N_s}$ (favoring large representations) and $a_R^{8N_s}$ (suppressing them).

**Ordering at $\beta \ll 1$ ($N_s = 1$):**

$$\lambda_\mathbf{1} > \lambda_\mathbf{3} = \lambda_{\bar{\mathbf{3}}} > \lambda_\mathbf{6} = \lambda_{\bar{\mathbf{6}}} > \lambda_\mathbf{8} > \lambda_\mathbf{10} = \lambda_{\overline{\mathbf{10}}} > \cdots \tag{11.5}$$

The first excited state is always $\mathbf{3}$ (or $\bar{\mathbf{3}}$), since it has the smallest non-trivial dimension ($d_\mathbf{3} = 3$) and the largest non-trivial reduced coefficient ($u_\mathbf{3}$).

**Why $\mathbf{6}$ precedes $\mathbf{8}$ in the ordering.** At strong coupling, $u_\mathbf{6} \sim \beta^2$ and $u_\mathbf{8} \sim \beta^2$ with comparable prefactors. However, $d_\mathbf{6} = 6 < d_\mathbf{8} = 8$, so the entropy cost of $\mathbf{8}$ is larger. The detailed ordering requires comparing $d_\mathbf{6}^3 u_\mathbf{6}^8$ vs $d_\mathbf{8}^3 u_\mathbf{8}^8$ at the given $\beta$ value. At sufficiently small $\beta$, the $u_R^8$ factor dominates and the ordering follows the Casimir hierarchy (smaller Casimir = larger eigenvalue).

**Gap ratios.** The ratio of the second gap to the first gap provides spectral information:

$$\frac{m_2}{m_1} = \frac{E_\mathbf{6}}{E_\mathbf{3}} = \frac{-3\ln 6 - 8\ln u_\mathbf{6}}{-3\ln 3 - 8\ln u_\mathbf{3}} \tag{11.6}$$

At strong coupling, $u_\mathbf{6} \approx u_\mathbf{3}^2$ (leading order), so:

$$\frac{m_2}{m_1} \approx \frac{-3\ln 6 - 16\ln u_\mathbf{3}}{-3\ln 3 - 8\ln u_\mathbf{3}} \approx 2 + \frac{3\ln 2 - 3\ln 3}{-3\ln 3 - 8\ln u_\mathbf{3}} \tag{11.7}$$

As $\beta \to 0$ (so $-\ln u_\mathbf{3} \to \infty$), $m_2/m_1 \to 2$. The gap ratios approach integer values at strong coupling, reflecting the approximate "quark model" structure where the excitation energy scales with the number of fundamental indices.

**Full gap ratio table at strong coupling ($\beta \to 0$, $N_s = 1$):**

| Level | $R$ | $d_R$ | $n(R)$ | $\epsilon_R / \epsilon_\mathbf{3}$ (asymptotic) |
|-------|-----|-------|--------|------------------------------------------|
| 1st excited | $\mathbf{3}$ | 3 | 1 | 1 |
| 2nd excited | $\mathbf{6}$ | 6 | 2 | 2 |
| 3rd excited | $\mathbf{8}$ | 8 | 2 | 2 |
| 4th excited | $\mathbf{10}$ | 10 | 3 | 3 |
| 5th excited | $\mathbf{15}$ | 15 | 3 | 3 |
| 6th excited | $\mathbf{27}$ | 27 | 4 | 4 |

Here $n(R)$ is the power of $\beta$ in the leading term of $u_R$, and the asymptotic gap ratio $n(R)$ emerges because $\epsilon_R \approx -3\ln d_R + 8n(R)\ln(1/\beta) + \cdots$, and the $\ln(1/\beta)$ term dominates as $\beta \to 0$.

### 11.4 N-ality and the String Spectrum

The $N$-ality (triality for SU(3)) of a representation determines its behavior under the center $\mathbb{Z}_3 \subset SU(3)$. Representations with $N$-ality $k = 0$ are center-blind (adjoint, $\mathbf{10}$, $\mathbf{27}$, ...) while those with $k = 1, 2$ carry fundamental or anti-fundamental center charge.

**Physical significance.** In the confined phase, the lowest excitation with $N$-ality $k$ corresponds to a string with $k$ units of fundamental flux. The mass gaps for different $N$-alities are:

- **$k = 0$:** Lowest state is $\mathbf{8}$ (adjoint). Gap: $\mu_\text{adj} = -3\ln 8 - 8\ln u_\mathbf{8}$
- **$k = 1$:** Lowest state is $\mathbf{3}$ (fundamental). Gap: $\mu_\text{fund} = -3\ln 3 - 8\ln u_\mathbf{3}$
- **$k = 2$:** Lowest state is $\bar{\mathbf{3}}$ (anti-fundamental). Gap: $\mu_{\bar{\text{fund}}} = \mu_\text{fund}$ (by charge conjugation)

The $k = 0$ sector is relevant for glueball masses, while the $k = 1, 2$ sectors describe string-like excitations. The global mass gap is $\mu_\text{fund}$ (the fundamental has the smallest gap).

**Casimir scaling.** At strong coupling, the ratio of string tensions for different $N$-alities follows the Casimir scaling hypothesis: $\sigma_R / \sigma_\mathbf{3} \approx C_2(R) / C_2(\mathbf{3})$. From our exact eigenvalues, the ratio of gaps at leading order is controlled by $n(R)$, which for the lowest representation of each $N$-ality gives approximate Casimir scaling.

### 11.5 Level Crossing at Weak Coupling

As $\beta$ increases toward $\beta_c$, the reduced coefficients $u_R(\beta)$ approach 1 (for all $R$), and the entropy factors $d_R^{3N_s}$ become the dominant contribution. Level crossings occur when two eigenvalues become equal:

$$\lambda_R = \lambda_{R'} \iff d_R^{3N_s} a_R^{8N_s} = d_{R'}^{3N_s} a_{R'}^{8N_s} \tag{11.8}$$

**First crossing:** $\lambda_\mathbf{1} = \lambda_\mathbf{3}$ at $u_\mathbf{3} = 3^{-3/8}$ (this is the deconfinement transition, SS10.5).

**Second crossing:** $\lambda_\mathbf{3} = \lambda_\mathbf{8}$ occurs at a higher $\beta$ value where:

$$3^{3N_s} a_\mathbf{3}^{8N_s} = 8^{3N_s} a_\mathbf{8}^{8N_s}$$

$$\left(\frac{a_\mathbf{3}}{a_\mathbf{8}}\right)^{8N_s} = \left(\frac{8}{3}\right)^{3N_s}$$

$$\frac{u_\mathbf{3}}{u_\mathbf{8}} = \left(\frac{8}{3}\right)^{3/8} \tag{11.9}$$

Beyond this coupling, $\lambda_\mathbf{8} > \lambda_\mathbf{3}$, and the adjoint representation dominates over the fundamental. At still higher couplings, representations with even larger dimensions take over.

**Sequence of level crossings.** As $\beta$ increases from 0 to $\infty$, the dominant representation shifts through a sequence:

$$R^* = \mathbf{1} \xrightarrow{\beta = \beta_c^{(1)}} \mathbf{3} \xrightarrow{\beta = \beta_c^{(2)}} \mathbf{8} \xrightarrow{\beta = \beta_c^{(3)}} \cdots$$

Each crossing represents a "phase transition" in the finite-volume system. On the infinite lattice ($N_s \to \infty$), these crossings sharpen to genuine first-order transitions (for SU(3)), with latent heat proportional to $N_s$.

### 11.6 Spectrum in the Confined Phase

In the confined phase ($\beta < \beta_c$), the spectrum has a clear gap structure:

$$\lambda_\mathbf{1} > \lambda_\mathbf{3} > \lambda_\mathbf{6} > \lambda_\mathbf{8} > \cdots \tag{11.10}$$

The ratios $\lambda_R / \lambda_\mathbf{1} = (d_R^3 u_R^8)^{N_s}$ are all less than 1 and decrease with increasing representation size. In the thermodynamic limit $N_s \to \infty$, only the ground state survives:

$$\frac{1}{N_s L}\ln Z_\text{FCC} \to 3\ln d_{R^*} + 8\ln a_{R^*}(\beta) \tag{11.11}$$

where $R^* = \mathbf{1}$ in the confined phase.

### 11.7 Correlation Length

The transfer matrix mass gap determines the correlation length along the [111] direction:

$$\xi(\beta) = \frac{1}{\mu(\beta)} = \frac{1}{-3\ln 3 - 8\ln u_\mathbf{3}(\beta)} \tag{11.12}$$

measured in units of the inter-layer spacing $d_{111} = a/\sqrt{3}$. In physical units:

$$\xi_\text{phys}(\beta) = \xi(\beta) \cdot d_{111} = \frac{a/\sqrt{3}}{-3\ln 3 - 8\ln u_\mathbf{3}(\beta)} \tag{11.13}$$

**Behavior in different regimes:**

| Regime | $\beta$ range | $\xi$ (lattice units) | Physical interpretation |
|--------|-------------|---------------------|----------------------|
| Deep strong coupling | $\beta \ll 1$ | $\xi \ll 1$ | Sub-lattice correlations; confinement |
| Moderate coupling | $\beta \sim 2\text{--}6$ | $\xi \sim 0.1\text{--}0.5$ | Short-range correlations |
| Near-critical | $\beta \lesssim \beta_c$ | $\xi \gg 1$ | Long-range correlations; scaling regime |
| At criticality | $\beta = \beta_c$ | $\xi = \infty$ | Divergent correlation length |

As $\beta \to \beta_c$ from below:

$$\xi(\beta) \approx \frac{1}{8 |u_\mathbf{3}'(\beta_c)| (\beta_c - \beta)} \tag{11.14}$$

to leading order, where $u_\mathbf{3}'(\beta_c)$ is the derivative of $u_\mathbf{3}$ at the critical point. The correlation length diverges as $(\beta_c - \beta)^{-1}$, consistent with a mean-field critical exponent $\nu = 1$ (expected for the large-dimension / strong-coupling regime).

### 11.8 Polyakov Loop and Center Symmetry

The transfer matrix formalism connects naturally to the Polyakov loop. The Polyakov loop is the trace of the product of temporal link variables around the periodic time direction:

$$L(\vec{x}) = \frac{1}{N_c}\text{Tr}\prod_{t=0}^{L-1} U_0(\vec{x}, t) \tag{11.15}$$

Its expectation value serves as an order parameter for the deconfinement transition. In the transfer matrix language:

$$\langle |L|^2 \rangle = \frac{\sum_R d_R \lambda_R^L}{\sum_R \lambda_R^L} \tag{11.16}$$

In the confined phase ($\beta < \beta_c$, $\lambda_\mathbf{1}$ dominates):

$$\langle |L|^2 \rangle \xrightarrow{L \to \infty} d_\mathbf{1} = 1 \quad (\text{with corrections } \sim e^{-\mu L})$$

The connected Polyakov loop correlator decays exponentially with the mass gap $\mu$, confirming the physical interpretation of $\mu$ as the inverse string tension (in temporal lattice units).

## 12. Decoupling Limit

**Status:** ESTABLISHED consistency check

### 12.1 What "Decoupling" Means

The decoupling limit is a thought experiment where we hypothetically remove all face-sharing constraints between cells, making each cell an independent system. This serves as a consistency check: the coupled (assembled) partition function should reduce to the product of isolated cell partition functions when the coupling is removed.

In the decoupled limit, each cell has its own independent representation label:
- Each isolated tetrahedron: $Z_{K_4} = \sum_R d_R^2 a_R^4$ (Prop 0.0.38)
- Each isolated octahedron: $Z_\text{oct} = \sum_R d_R^2 a_R^8$ (Prop 2.5.2b, Lemma 10.7.1)

### 12.2 Decoupled Eigenvalues

In the decoupled limit, the "transfer matrix" for a single slab factorizes into independent cell contributions. Per slab (between two adjacent layers), there are $2N_s$ tetrahedra and $N_s$ octahedra. The decoupled partition function for $L$ slabs is:

$$Z_\text{decoupled}(L) = \prod_\text{slabs} \prod_\text{cells in slab} Z_\text{cell}^{(\text{isolated})} \tag{12.1}$$

However, this factorization is not directly comparable to the transfer matrix trace formula, because the decoupled system has $3N_s$ independent representation labels per slab (one per cell), not a single label per slab as in the coupled case.

The correct comparison is at the level of partition functions. For the full lattice with $L$ slabs:

$$Z_\text{decoupled} = \left[\sum_R d_R^2 a_R^4\right]^{2N_s L} \times \left[\sum_R d_R^2 a_R^8\right]^{N_s L} \tag{12.2}$$

### 12.3 Comparison: Coupled vs Decoupled

**Coupled (Prop 2.5.2b):**

$$Z_\text{coupled} = \sum_R d_R^{3N_s L} a_R^{8N_s L} \tag{12.3}$$

**Decoupled (12.2):**

$$Z_\text{decoupled} = \left[\sum_R d_R^2 a_R^4\right]^{2N_s L} \left[\sum_R d_R^2 a_R^8\right]^{N_s L} \tag{12.4}$$

These are manifestly different:

1. The coupled formula is a SINGLE sum over $R$ (all cells share the same label).
2. The decoupled formula is a PRODUCT of sums (each cell has an independent label).

At strong coupling ($\beta \ll 1$), both are dominated by $R = \mathbf{1}$:

$$Z_\text{coupled} \approx a_\mathbf{1}^{8N_s L}, \qquad Z_\text{decoupled} \approx a_\mathbf{1}^{8N_s L}$$

So they agree to leading order. The difference appears in the sub-leading corrections:

$$\ln Z_\text{decoupled} - \ln Z_\text{coupled} = \ln\!\left(\frac{Z_\text{decoupled}}{Z_\text{coupled}}\right) \geq 0 \tag{12.5}$$

The inequality follows from Prop 2.5.2b, Proposition 13.2.1: the coupled system has fewer configurations (one global label) than the decoupled system ($3N_s L$ independent labels), so $Z_\text{coupled} \leq Z_\text{decoupled}$.

### 12.4 What the Comparison Shows

The coupling through shared faces has three effects:

1. **Degree-of-freedom reduction.** The number of independent representation labels drops from $3N_s$ (decoupled, per slab) to $1$ (coupled). This is the essence of the global label constraint.

2. **Gap modification.** The intensive mass gap changes from the decoupled value to the coupled value. In the decoupled case, each cell has its own gap (e.g., $\Delta_{K_4} = -2\ln 3 - 4\ln u_\mathbf{3}$ for each K$_4$), but these are independent. In the coupled case, the single gap $\mu = -3\ln 3 - 8\ln u_\mathbf{3}$ governs the entire system.

3. **Entropy reduction.** The free energy per cell is higher in the coupled system (fewer accessible configurations), which manifests as the inequality $f_\text{coupled} \geq f_\text{decoupled}$.

The key physical point: coupling through shared faces is a genuine 3D effect that fundamentally changes the dynamics. The coupled system is not simply a product of independent cells.

### 12.5 Quantitative Comparison at $\beta = 1$, $N_s = 1$, $L = 1$

For a single primitive cell ($N_s = 1$, $L = 1$):

**Coupled:**

$$Z_\text{coupled} = \sum_R d_R^3 a_R^8 \approx a_\mathbf{1}^8 + 2 \times 27 a_\mathbf{3}^8 + \cdots \tag{12.6}$$

At $\beta = 1$: $a_\mathbf{1} \approx 1.028$, $a_\mathbf{3} \approx 0.0618$, so:

$$Z_\text{coupled} \approx 1.028^8 + 54 \times 0.0618^8 \approx 1.248 + 54 \times 2.18 \times 10^{-10} \approx 1.248 \tag{12.7}$$

The correction from $R = \mathbf{3}$ is negligible ($\sim 10^{-8}$).

**Decoupled:**

$$Z_\text{decoupled} = [Z_{K_4}]^2 \times Z_\text{oct} = \left[\sum_R d_R^2 a_R^4\right]^2 \times \left[\sum_R d_R^2 a_R^8\right] \tag{12.8}$$

At $\beta = 1$:
- $Z_{K_4} \approx a_\mathbf{1}^4 + 2 \times 9 a_\mathbf{3}^4 \approx 1.117 + 18 \times 1.46 \times 10^{-5} \approx 1.117$
- $Z_\text{oct} \approx a_\mathbf{1}^8 + 2 \times 9 a_\mathbf{8}^8 \approx 1.248$

$$Z_\text{decoupled} \approx 1.117^2 \times 1.248 \approx 1.557 \tag{12.9}$$

**Ratio:** $Z_\text{decoupled}/Z_\text{coupled} \approx 1.557/1.248 \approx 1.25$. The entropy difference $\Delta s = \frac{1}{3}\ln(1.25) \approx 0.074$ per cell --- small but nonzero.

### 12.6 Decoupling in the Thermodynamic Limit

In the thermodynamic limit ($N_s, L \to \infty$), the free energy per cell differs between coupled and decoupled systems:

$$f_\text{coupled} = -\frac{1}{3}\max_R\left[3\ln d_R + 8\ln a_R\right] \tag{12.10}$$

$$f_\text{decoupled} = -\frac{2}{3}\ln\!\left(\max_R d_R^2 a_R^4\right) - \frac{1}{3}\ln\!\left(\max_R d_R^2 a_R^8\right) \tag{12.11}$$

At strong coupling (where $R^* = \mathbf{1}$ in all cases), both reduce to $f = -\frac{8}{3}\ln a_\mathbf{1}$, and the difference is exponentially small. At weak coupling, the decoupled system can have different dominant representations for tetrahedra and octahedra (since they have different face counts), while the coupled system is forced to a single dominant representation.

## 13. Strong Coupling Expansion

**Status:** ESTABLISHED technique (strong coupling expansion), 🔶 NOVEL on FCC transfer matrix

### 13.1 Leading Term: $R = \mathbf{1}$ (Trivial Representation)

The ground-state eigenvalue of the transfer matrix is:

$$\lambda_\mathbf{1}(\beta, N_s) = a_\mathbf{1}(\beta)^{8N_s} \tag{13.1}$$

since $d_\mathbf{1} = 1$. At strong coupling:

$$a_\mathbf{1}(\beta) = 1 + \frac{\beta^2}{36} + O(\beta^4) \tag{13.2}$$

so the ground-state eigenvalue is:

$$\lambda_\mathbf{1} = \left(1 + \frac{\beta^2}{36} + O(\beta^4)\right)^{8N_s} \approx \exp\!\left(\frac{8N_s \beta^2}{36}\right) = \exp\!\left(\frac{2N_s \beta^2}{9}\right) \tag{13.3}$$

for $\beta \ll 1$.

### 13.2 First Correction: $R = \mathbf{3}$ (Fundamental)

The first excited eigenvalue is:

$$\lambda_\mathbf{3}(\beta, N_s) = 3^{3N_s} \, a_\mathbf{3}(\beta)^{8N_s} = 3^{3N_s} \, u_\mathbf{3}(\beta)^{8N_s} \, a_\mathbf{1}(\beta)^{8N_s} \tag{13.4}$$

Using $u_\mathbf{3}(\beta) \approx \beta/18$ at leading order:

$$\lambda_\mathbf{3} \approx 3^{3N_s} \left(\frac{\beta}{18}\right)^{8N_s} a_\mathbf{1}^{8N_s} = \frac{3^{3N_s} \beta^{8N_s}}{18^{8N_s}} \, a_\mathbf{1}^{8N_s} \tag{13.5}$$

$$= \frac{3^{3N_s} \beta^{8N_s}}{2^{8N_s} \cdot 3^{16N_s}} \, a_\mathbf{1}^{8N_s} = \frac{\beta^{8N_s}}{2^{8N_s} \cdot 3^{13N_s}} \, a_\mathbf{1}^{8N_s} \tag{13.6}$$

The ratio to the ground state:

$$\frac{\lambda_\mathbf{3}}{\lambda_\mathbf{1}} = 3^{3N_s} u_\mathbf{3}^{8N_s} = \left(3^3 u_\mathbf{3}^8\right)^{N_s} = \left(\frac{27 \beta^8}{18^8}\right)^{N_s} \tag{13.7}$$

For $\beta = 1$: $\lambda_\mathbf{3}/\lambda_\mathbf{1} \approx (27/18^8)^{N_s} \approx (3.8 \times 10^{-9})^{N_s}$, which is spectacularly small even for $N_s = 1$. The strong coupling expansion is under excellent control.

### 13.3 Mass Gap Expansion

The intensive mass gap at strong coupling is:

$$\mu(\beta) = -3\ln 3 - 8\ln u_\mathbf{3}(\beta) \tag{13.8}$$

Substituting $u_\mathbf{3} \approx \beta/18 + c_3 \beta^3 + O(\beta^5)$ (odd powers only, from the SU(3) character expansion):

$$\mu(\beta) = 8\ln\!\left(\frac{18}{\beta}\right) - 3\ln 3 + O(\beta^2) \tag{13.9}$$

**Properties:**

1. **Divergence at $\beta = 0$:** $\mu \to +\infty$ logarithmically. The mass gap diverges in the $\beta \to 0$ limit.

2. **Leading coefficient:** The coefficient of $-\ln\beta$ is $8$ (from the 8 faces per layer). For comparison, the K$_4$ transfer matrix has coefficient $10$ (from 10 plaquettes per time step).

3. **Additive constant:** $8\ln 18 - 3\ln 3 = 8 \times 2.890 - 3.296 \approx 19.8$ (at $\beta = 1$).

4. **Next-order correction:** The $O(\beta^2)$ correction comes from the $\beta^2/36$ correction to $a_\mathbf{1}$ and the cubic correction to $u_\mathbf{3}$. These modify the mass gap by a relative correction of order $\beta^2$.

### 13.4 Plaquette Expectation Value from Transfer Matrix

The average plaquette on the FCC lattice can be computed from the transfer matrix. In the thermodynamic limit ($L \to \infty$), the partition function is dominated by the largest eigenvalue $\lambda_{R^*}$:

$$\frac{1}{N}\ln Z_\text{FCC} = \frac{1}{N_s L}\sum_R \lambda_R^L \xrightarrow{L\to\infty} \frac{1}{N_s}\ln \lambda_{R^*} \tag{13.10}$$

The plaquette expectation value is:

$$\langle P \rangle_\text{FCC} = \frac{1}{8N}\frac{\partial \ln Z_\text{FCC}}{\partial \beta} \tag{13.11}$$

For finite $L$:

$$\langle P \rangle = \frac{\sum_R \lambda_R^{L-1} \lambda_R'(\beta)}{\sum_R \lambda_R^L} \cdot \frac{L}{8N_s L} = \frac{1}{8N_s} \frac{\sum_R \lambda_R^{L-1} \frac{\partial \lambda_R}{\partial \beta}}{\sum_R \lambda_R^L} \tag{13.12}$$

where $\lambda_R'(\beta) = \frac{\partial}{\partial\beta}\lambda_R = d_R^{3N_s} \cdot 8N_s \cdot a_R^{8N_s - 1} a_R'(\beta)$.

In the thermodynamic limit ($L \to \infty$), only $R^* = \mathbf{1}$ contributes (at strong coupling):

$$\langle P \rangle_\text{FCC} \xrightarrow{L\to\infty} \frac{1}{8N_s} \cdot \frac{\partial \ln \lambda_\mathbf{1}}{\partial \beta} = \frac{1}{8N_s} \cdot 8N_s \cdot \frac{a_\mathbf{1}'(\beta)}{a_\mathbf{1}(\beta)} = \frac{a_\mathbf{1}'(\beta)}{a_\mathbf{1}(\beta)} \tag{13.13}$$

At strong coupling, $a_\mathbf{1} \approx 1$ and $a_\mathbf{1}' \approx \beta/18$, so:

$$\boxed{\langle P \rangle_\text{FCC} \approx \frac{\beta}{18} \qquad (\beta \ll 1)} \tag{13.14}$$

This matches the universal strong-coupling result for SU(3) with the Wilson action: $\langle P \rangle = \beta/(2N_c^2) = \beta/18$. The agreement is a nontrivial consistency check --- the lattice geometry (FCC vs hypercubic vs single K$_4$) does not affect the leading-order strong coupling plaquette.

### 13.5 Free Energy from Transfer Matrix

The free energy per unit cell in the thermodynamic limit is:

$$f(\beta) = -\lim_{N_s, L \to \infty} \frac{1}{3N_s L} \ln Z_\text{FCC} = -\frac{1}{3}\left(3\ln d_{R^*} + 8\ln a_{R^*}(\beta)\right) \tag{13.15}$$

where $R^*$ is the dominant representation. In the confined phase ($\beta < \beta_c$), $R^* = \mathbf{1}$:

$$f(\beta) = -\frac{8}{3}\ln a_\mathbf{1}(\beta) \approx -\frac{8}{3}\cdot\frac{\beta^2}{36} = -\frac{2\beta^2}{27} \qquad (\beta \ll 1) \tag{13.16}$$

The transfer matrix provides a systematic way to compute $f(\beta)$ at any coupling:

$$f(\beta) = -\frac{1}{3N_s}\ln \lambda_{R^*}(\beta, N_s) \tag{13.17}$$

### 13.6 Higher-Order Strong Coupling Corrections

The strong coupling expansion of the intensive mass gap to next order requires the $O(\beta^2)$ correction to $u_\mathbf{3}$. From Prop 0.0.38 SS5.1, the heat kernel coefficients admit a Taylor expansion:

$$a_\mathbf{1}(\beta) = 1 + \frac{\beta^2}{36} + O(\beta^4) \tag{13.18}$$

$$a_\mathbf{3}(\beta) = \frac{\beta}{18} + O(\beta^3) \tag{13.19}$$

Therefore:

$$u_\mathbf{3}(\beta) = \frac{a_\mathbf{3}}{a_\mathbf{1}} = \frac{\beta/18 + O(\beta^3)}{1 + \beta^2/36 + O(\beta^4)} = \frac{\beta}{18}\left(1 - \frac{\beta^2}{36} + O(\beta^4)\right) + O(\beta^3) \tag{13.20}$$

$$= \frac{\beta}{18} + O(\beta^3) \tag{13.21}$$

The $O(\beta^2)$ correction to $\mu(\beta)$ comes from:

$$\mu(\beta) = -3\ln 3 + 8\ln 18 - 8\ln\beta + O(\beta^2) \tag{13.22}$$

The $O(\beta^2)$ term involves both the cubic correction to $a_\mathbf{3}$ and the quadratic correction to $a_\mathbf{1}$. Its explicit computation requires the next-order Weyl integral coefficients.

### 13.7 Convergence of the Representation Sum

The partition function $Z_\text{FCC} = \sum_R d_R^{3N} a_R^{8N}$ converges absolutely for all $\beta > 0$. To verify this, we need the asymptotic behavior of $a_R(\beta)$ for large representations.

**Lemma 13.7.1 (Heat kernel decay).** For fixed $\beta > 0$ and SU(3) representation $(p,q)$ with $C_2(p,q) = (p^2 + q^2 + pq + 3p + 3q)/3$:

$$a_{(p,q)}(\beta) \sim \exp\!\left(-\frac{\beta}{6} C_2(p,q)\right) \qquad \text{as } C_2 \to \infty \tag{13.23}$$

This is the heat kernel on SU(3): at "time" $\beta/6$, the kernel evaluated at the identity decays exponentially with the Casimir (Menotti & Onofri 1981).

**Convergence proof.** For large $(p,q)$:

$$d_{(p,q)}^{3N} a_{(p,q)}^{8N} \sim \left[\frac{(p+q)^3}{2}\right]^{3N} \exp\!\left(-\frac{4N\beta}{3}(p^2+q^2+pq)\right) \tag{13.24}$$

The exponential decay with $p^2 + q^2$ overwhelms the polynomial growth of $d_R^{3N}$ for any fixed $\beta > 0$ and $N \geq 1$. The sum converges absolutely and uniformly on compact subsets of $\beta > 0$. $\square$

**Practical truncation.** At coupling $\beta$ and lattice size $N$, the representation sum can be truncated at Casimir $C_\text{max} \sim (3N/\beta) \ln(1/\epsilon)$ to achieve relative error $\epsilon$. At strong coupling ($\beta \leq 2$), retaining only $R = \mathbf{1}, \mathbf{3}, \bar{\mathbf{3}}$ gives relative error $< 10^{-15}$ per cell.

## Appendix A: Consistency Checks

### A.1 Trace Consistency

The transfer matrix eigenvalues must satisfy the trace formula for all $L \geq 1$:

$$\text{Tr}(\hat{T}^L) = \sum_R \lambda_R^L = \sum_R d_R^{3N_s L} a_R^{8N_s L} = Z_\text{FCC}(\beta, N_s L) \tag{A.1}$$

This is automatically satisfied by construction (SS9.3). As a non-trivial check, consider $L = 2$:

$$\text{Tr}(\hat{T}^2) = \sum_R \lambda_R^2 = \sum_R d_R^{6N_s} a_R^{16N_s} \tag{A.2}$$

This should equal $Z_\text{FCC}(\beta, 2N_s)$ with $V = 2N_s$, $E = 12N_s$, $F = 16N_s$, $\chi_2 = 2N_s - 12N_s + 16N_s = 6N_s$:

$$Z_\text{FCC}(\beta, 2N_s) = \sum_R d_R^{6N_s} a_R^{16N_s} \quad \checkmark \tag{A.3}$$

### A.2 Reflection Positivity

The transfer matrix $\hat{T}$ has all positive eigenvalues ($\lambda_R > 0$ for all $R$ and $\beta > 0$), which implies:

1. $\hat{T}$ is a positive operator on $\mathcal{H}$
2. The partition function $Z = \text{Tr}(\hat{T}^L) > 0$ for all $L$
3. Correlation functions satisfy Osterwalder-Schrader reflection positivity

This is essential for the Euclidean-to-Minkowski continuation: reflection positivity guarantees that the transfer matrix can be written as $\hat{T} = e^{-\hat{H}}$ for a self-adjoint Hamiltonian $\hat{H}$ with real spectrum.

**Explicit Hamiltonian.** From $\hat{T}|R\rangle = \lambda_R|R\rangle$, define:

$$\hat{H}|R\rangle = E_R|R\rangle, \qquad E_R = -\ln \lambda_R = -3N_s \ln d_R - 8N_s \ln a_R(\beta) \tag{A.4}$$

The ground state energy is $E_\mathbf{1} = -8N_s \ln a_\mathbf{1}(\beta) < 0$ (since $a_\mathbf{1} > 1$ for $\beta > 0$), and excitation energies are:

$$\Delta E_R = E_R - E_\mathbf{1} = -3N_s \ln d_R - 8N_s \ln u_R(\beta) > 0 \qquad (\beta < \beta_c) \tag{A.5}$$

### A.3 Isotropy Check

The (111) direction was chosen for the layer decomposition, but the FCC lattice has cubic symmetry. One could equally slice along [100] or [110]. The transfer matrix eigenvalues should be consistent regardless of slicing direction (the partition function is unique).

**Claim.** The partition function $Z_\text{FCC} = \sum_R d_R^{3N} a_R^{8N}$ is independent of the slicing direction. This follows because $Z$ is determined by the topology of the 2-skeleton ($V$, $E$, $F$), which does not depend on how the lattice is sliced into layers.

However, the transfer matrix ITSELF depends on the slicing:

- **[111] slicing:** $\lambda_R = d_R^{3N_s} a_R^{8N_s}$ with $N_s = N/L_{111}$
- **[100] slicing:** $\lambda_R^{[100]} = d_R^{3N_s'} a_R^{8N_s'}$ with $N_s' = N/L_{100}$

Since $N_s L_{111} = N_s' L_{100} = N$, the trace $\text{Tr}(\hat{T}^L) = Z$ is the same in both cases. The intensive mass gap $\mu = -3\ln 3 - 8\ln u_\mathbf{3}$ is also independent of the slicing direction (it depends only on $\beta$).

### A.4 ABC Stacking and Transfer Matrix Periodicity

The FCC lattice along [111] has ABCABC stacking with period 3. One might worry that the transfer matrix should be a product of three DIFFERENT matrices $\hat{T}_A \hat{T}_B \hat{T}_C$ (one for each slab type: A-to-B, B-to-C, C-to-A).

**Resolution.** Because the global label constraint forces all face labels to agree regardless of cell type, the transfer matrix for each slab type is the same:

$$\hat{T}_{AB} = \hat{T}_{BC} = \hat{T}_{CA} = \hat{T} \tag{A.6}$$

This is because each slab (regardless of its A, B, or C position) contains exactly the same combinatorics: $2N_s$ tetrahedra, $N_s$ octahedra, with the same face, edge, and vertex counts. The lateral displacement between A, B, and C layers affects only the geometric embedding in $\mathbb{R}^3$, not the combinatorial structure of the 2-skeleton.

Therefore the partition function for $L = 3M$ layers is:

$$Z = \text{Tr}\!\left[(\hat{T}_{AB}\hat{T}_{BC}\hat{T}_{CA})^M\right] = \text{Tr}(\hat{T}^{3M}) = \sum_R \lambda_R^{3M} \tag{A.7}$$

and more generally for any $L$:

$$Z = \text{Tr}(\hat{T}^L) = \sum_R \lambda_R^L \tag{A.8}$$

The ABC periodicity is invisible to the transfer matrix because the combinatorial structure is translationally invariant along [111].

### A.5 Relation to Temporal vs Spatial Transfer Matrix

It is important to distinguish the transfer matrix constructed here (spatial slicing along [111]) from the temporal transfer matrix of Prop 0.0.38a (temporal extension of a single K$_4$).

| Property | Temporal (Prop 0.0.38a) | Spatial (this work) |
|----------|------------------------|---------------------|
| Geometry | K$_4 \times S^1_{n_t}$ | FCC sliced along [111] |
| Spatial slice | Single K$_4$ | (111) layer with $N_s$ cells |
| Eigenvalue | $t_R = d_R^4 a_R^{10}$ | $\lambda_R = d_R^{3N_s} a_R^{8N_s}$ |
| Mass gap | $-4\ln 3 - 10\ln u_3$ | $N_s(-3\ln 3 - 8\ln u_3)$ |
| Hilbert space per site | $b_1 = 3$ loops | 1 global label |
| Extensivity | Not extensive (single cell) | Extensive ($\propto N_s$) |
| Thermodynamic limit | N/A (single cell) | $N_s \to \infty$ well-defined |

The temporal transfer matrix is a building block; the spatial transfer matrix constructed here operates on the assembled lattice and captures the full 3D physics. The intensive mass gap $\mu_\text{FCC} = -3\ln 3 - 8\ln u_3$ differs from the single-cell gap $m_\text{gap}^{(K_4)} = -4\ln 3 - 10\ln u_3$ because the assembly changes the entropy-energy balance through face sharing.
