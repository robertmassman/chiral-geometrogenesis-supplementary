## 1. Statement

**Definition 1.1.4 (Stella Diagram Rules).** A *stella diagram* is a directed labeled graph $\mathcal{D} = (V, E, \phi, \sigma)$ drawn on the stella octangula graph $\Gamma(\partial\mathcal{S})$, subject to the rules below. The quadruple consists of:
- $V \subseteq \{R, G, B, \bar{R}, \bar{G}, \bar{B}\}$: a subset of color vertices
- $E$: a set of directed edges between vertices, each carrying a phase label
- $\phi: E \to U(1)$: the phase assignment (from Definition 0.1.2)
- $\sigma: E \to \{+1, -1\}$: the chirality assignment (provisional; justified in Phase 2 via Theorem 2.2.4)

A stella diagram represents a physical state or process if and only if it satisfies the **closure rule** (Rule 5 below).

## 2. The Stella Graph

### 2.1 Vertices

The stella graph $\Gamma(\partial\mathcal{S})$ has six color vertices, partitioned into two sets by tetrahedron membership:

$$V_+ = \{R, G, B\} \subset T_+, \qquad V_- = \{\bar{R}, \bar{G}, \bar{B}\} \subset T_-$$

Each vertex $v$ carries a **color charge** identified with an SU(3) weight vector (Theorem 1.1.1):

| Vertex | Tetrahedron | Weight vector $\vec{w} = (T_3,\, T_8)$ | Phase $\phi$ |
|--------|-------------|----------------------------------------|---------------|
| $R$      | $T_+$ | $\left(+\tfrac{1}{2},\, +\tfrac{1}{2\sqrt{3}}\right)$ | $0$ |
| $G$      | $T_+$ | $\left(-\tfrac{1}{2},\, +\tfrac{1}{2\sqrt{3}}\right)$ | $\tfrac{2\pi}{3}$ |
| $B$      | $T_+$ | $\left(0,\, -\tfrac{1}{\sqrt{3}}\right)$ | $\tfrac{4\pi}{3}$ |
| $\bar{R}$ | $T_-$ | $-\vec{w}_R$ | $0$ (conjugate) |
| $\bar{G}$ | $T_-$ | $-\vec{w}_G$ | $\tfrac{2\pi}{3}$ (conjugate) |
| $\bar{B}$ | $T_-$ | $-\vec{w}_B$ | $\tfrac{4\pi}{3}$ (conjugate) |

**Remark.** The singlet vertices $W \in T_+$ and $\bar{W} \in T_-$ (Definition 0.1.3, §2.1) do not carry independent color charge and do not appear in stella diagrams. They correspond to the Cartan-neutral direction and are implicitly present at color-singlet junction points.

### 2.2 Edges

Edges in $\Gamma(\partial\mathcal{S})$ are of three types:

1. **Intra-$T_+$ edges:** Connect vertices within $T_+$. There are $\binom{3}{2} = 3$ such edges: $R\text{-}G$, $G\text{-}B$, $B\text{-}R$.
2. **Intra-$T_-$ edges:** Connect vertices within $T_-$. There are 3: $\bar{R}\text{-}\bar{G}$, $\bar{G}\text{-}\bar{B}$, $\bar{B}\text{-}\bar{R}$.
3. **Cross edges (conjugation lines):** Connect each vertex to its antipodal partner: $R\text{-}\bar{R}$, $G\text{-}\bar{G}$, $B\text{-}\bar{B}$.

Total: 9 edges in the diagram graph. (The full stella has 12 geometric edges including those to $W, \bar{W}$; the diagram graph uses only the 6 color-carrying vertices.)

**Why only 9 edges?** The 6 color vertices admit $\binom{6}{2} = 15$ possible edges. The 6 excluded **off-diagonal cross edges** ($R\text{-}\bar{G}$, $R\text{-}\bar{B}$, etc.) connect non-antipodal vertices across tetrahedra. These are excluded because:
1. **Topological:** $\partial\mathcal{S} = \partial T_+ \sqcup \partial T_-$ is a disjoint union (Definition 0.1.1). The only inter-tetrahedra identification is the antipodal conjugation map $\mathcal{I}$ (Theorem 1.1.2), which pairs $v \leftrightarrow \bar{v}$.
2. **Composite:** Any off-diagonal cross process ($R \to \bar{G}$) decomposes into intra-tetrahedron propagation followed by conjugation: $R \to G$ (within $T_+$) then $G \to \bar{G}$ (via $\mathcal{I}$). The off-diagonal cross edges are not independent diagram elements.
3. **Physical:** In QCD, gluon exchange preserves the quark-antiquark distinction. A quark can change color ($R \to G$) or annihilate with its own anticolor ($R + \bar{R} \to \text{singlet}$), but there is no elementary vertex coupling $R$ directly to $\bar{G}$ without an intermediate gluon that also changes the other end.

### 2.3 Faces

Each triangular face of a tetrahedron defines an elementary **Wilson loop** (Proposition 2.5.2a):

$$\triangle_{+} = R \to G \to B \to R \qquad \text{(face of } T_+\text{)}$$
$$\triangle_{-} = \bar{R} \to \bar{G} \to \bar{B} \to \bar{R} \qquad \text{(face of } T_-\text{)}$$

## 3. The Nine Diagram Rules

**Forward-dependency note:** Rules 3 (Chirality) and 7 (Wilson Loop) reference Phase 2 results (Theorem 2.2.4 and Proposition 2.5.2a respectively). These rules are stated here as *conventions* whose physical justification is deferred. Within Phase 1, they should be treated as provisional: the diagram formalism is fully functional without them for classifying kinematic states (mesons, baryons via Rule 5), but the dynamical content (preferred orientation, area law) requires Phase 2 machinery.

### Rule 1: Color Vertex

$$\boxed{\text{Each vertex } v \in \{R, G, B, \bar{R}, \bar{G}, \bar{B}\} \text{ carries color charge } \vec{w}_v \text{ and phase } \phi_v.}$$

**Source:** Definition 0.1.2 (phase values), Theorem 1.1.1 (weight vectors).

Draw as a colored dot:
- $T_+$ vertices: $R$ (red), $G$ (green), $B$ (blue)
- $T_-$ vertices: $\bar{R}$ (cyan), $\bar{G}$ (magenta), $\bar{B}$ (yellow)

### Rule 2: Directed Edge (Color Propagator)

$$\boxed{v_1 \xrightarrow{\;\omega^{\Delta c}\;} v_2 \quad \text{where } \omega = e^{2\pi i/3}, \quad \Delta c = \frac{\phi_{v_2} - \phi_{v_1}}{2\pi/3}.}$$

**Source:** Definition 0.1.2 (phase differences).

Each directed edge carries a **phase factor** $\omega^{\Delta c}$ determined by the phase difference between source and target vertices. The three elementary phase factors on $T_+$ are:

| Edge | Phase factor | Value |
|------|-------------|-------|
| $R \to G$ | $\omega^1 = e^{2\pi i/3}$ | $-\tfrac{1}{2} + \tfrac{\sqrt{3}}{2}i$ |
| $G \to B$ | $\omega^1 = e^{2\pi i/3}$ | $-\tfrac{1}{2} + \tfrac{\sqrt{3}}{2}i$ |
| $B \to R$ | $\omega^1 = e^{2\pi i/3}$ | $-\tfrac{1}{2} + \tfrac{\sqrt{3}}{2}i$ |

All three carry the same phase factor $\omega$ because the phases are equally spaced by $2\pi/3$.

**Reversal rule:** Reversing an edge conjugates the phase factor:

$$v_2 \to v_1 \quad \text{carries} \quad \omega^{-\Delta c} = (\omega^{\Delta c})^*$$

### Rule 3: Chirality (Orientation) — *Provisional*

$$\boxed{\text{The physical orientation is } R \to G \to B \text{ (counterclockwise in weight space).}}$$

**Source:** Theorem 2.2.4 (Anomaly-Driven Chirality Selection) — Phase 2.

**Provisional status:** This rule selects a preferred orientation for phase propagation on the stella graph. The physical justification — that the net positive instanton topological charge $\langle Q \rangle > 0$ fixes the rotation direction — requires 4D Euclidean spacetime and a gauge action, which are Phase 2 constructs (Theorem 2.2.4). Within Phase 1 (pre-geometric), this rule is adopted as a *convention*: the forward orientation $R \to G \to B$ is declared preferred, with physical justification deferred to Phase 2. **Any Phase 1 result that depends on Rule 3 inherits a Phase 2 dependency.**

In stella diagrams:

- **$R \to G \to B$ (forward):** Declared physical chirality (justified in Phase 2).
- **$R \to B \to G$ (reverse):** Dynamically disfavored (Phase 2 derivation).

**Convention:** Draw forward edges as solid arrows; reverse edges as dashed.

### Rule 4: Charge Conjugation

$$\boxed{\mathcal{I}: v \mapsto \bar{v} \quad \text{(point reflection } T_+ \leftrightarrow T_-\text{)}}$$

**Source:** Theorem 1.1.2 (Charge Conjugation as Point Reflection).

The conjugation map $\mathcal{I}: \vec{r} \mapsto -\vec{r}$ exchanges each vertex with its antipodal partner:

$$R \leftrightarrow \bar{R}, \quad G \leftrightarrow \bar{G}, \quad B \leftrightarrow \bar{B}$$

Draw conjugation lines as dotted edges connecting antipodal pairs.

**Properties:**
- $\mathcal{I}^2 = \mathrm{id}$ (involution)
- $\mathcal{I}$ preserves edge structure: if $v_1 \to v_2$ is an edge in $T_+$, then $\bar{v}_1 \to \bar{v}_2$ is an edge in $T_-$
- $\mathcal{I}$ reverses weight vectors: $\vec{w}_{\bar{v}} = -\vec{w}_v$

### Rule 5: Closure (Confinement Selection Rule)

$$\boxed{\text{A stella diagram represents a physical state} \iff \sum_{v \in V_{\text{state}}} \vec{w}_v = \vec{0}}$$

The sum runs over **all color charges** in the state, where quarks ($v \in T_+$) contribute their weight vector $\vec{w}_v$ and antiquarks ($\bar{v} \in T_-$) contribute $\vec{w}_{\bar{v}} = -\vec{w}_v$ (Rule 4). No additional sign factors are needed — the conjugation is already encoded in the weight vectors.

**Source:** Theorem 1.1.3 (Color Confinement Geometry).

**Verification:**
- Meson: $\vec{w}_R + \vec{w}_{\bar{R}} = \vec{w}_R + (-\vec{w}_R) = \vec{0}$ ✅
- Baryon: $\vec{w}_R + \vec{w}_G + \vec{w}_B = \vec{0}$ ✅ (tracelessness of SU(3))
- Wrong pair: $\vec{w}_R + \vec{w}_{\bar{G}} = \vec{w}_R - \vec{w}_G = (1, 0) \neq \vec{0}$ ✅ (octet, not singlet)

Equivalently: the total winding number (Rule 9) around any physical diagram is a multiple of $2\pi$:

$$\Phi = \frac{2\pi}{3}\sum \Delta c_i = 0 \pmod{2\pi}$$

**Physical meaning:** Only color-neutral (singlet) configurations correspond to observable particles. Open diagrams carry net color charge and are confined — they cannot exist as asymptotic states.

**Note on status:** This rule encodes the *kinematic* content of confinement (which states are color-neutral), not the *dynamical* mechanism (why colored states are forbidden). The dynamical enforcement comes from Theorem 2.5.2 (Dynamical Confinement) and Proposition 2.5.2a (Wilson Loop Area Law). See Theorem 1.1.3 §0 for the honest distinction.

### Rule 6: Gluon Line (Adjoint Propagator)

$$\boxed{v_1 \underset{g_{c_1 c_2}}{\sim\!\sim\!\sim} v_2 \quad \text{carries adjoint color charge } \vec{w}_{v_1} - \vec{w}_{v_2} \in \mathbf{8}}$$

**Source:** Theorem 1.1.1 (SU(3) $\leftrightarrow$ Stella, adjoint representation).

A gluon exchange between two color vertices is represented by a wavy line. The gluon carries the color difference: it transforms the source vertex from color $c_1$ to color $c_2$ and the target vertex from $c_2$ to $c_1$. The eight gluon species correspond to the six off-diagonal generators (color-changing) and two diagonal generators (color-preserving) of SU(3).

**Diagonal (Cartan) gluons:** The formula $\vec{w}_{v_1} - \vec{w}_{v_2}$ gives $\vec{0}$ when $v_1 = v_2$, so the two diagonal gluons ($T^3$ and $T^8$, corresponding to the Cartan subalgebra) do not appear as edges between distinct vertices. Instead, they act as **self-energy insertions** on a single vertex — they modify the amplitude at a color vertex without changing its color. In stella diagrams, diagonal gluon effects are absorbed into vertex weights and do not require separate graphical representation.

**Diagram convention:** Draw gluon lines as wavy/coiled lines between vertices, labeled $g_{c_1 c_2}$.

### Rule 7: Wilson Loop (Face Amplitude)

$$\boxed{W(\triangle) = \mathrm{tr}\,\mathcal{P}\exp\left(-ig\oint_\triangle A_\mu\, dx^\mu\right) \sim e^{-\sigma \cdot A(\triangle)}}$$

**Source:** Proposition 2.5.2a (Wilson Loop Area Law from Geometry).

A closed triangular path around one face of $T_+$ or $T_-$ defines an elementary Wilson loop. The area law gives its expectation value in terms of the string tension $\sigma$ and the face area $A(\triangle)$:

$$A(\triangle_{T_+}) = \frac{\sqrt{3}}{4}\,a^2$$

where $a$ is the edge length of the tetrahedron, related to $R_\text{stella}$ by $a = \tfrac{2\sqrt{2}}{\sqrt{3}}\,R_\text{stella}$.

**Diagram convention:** Draw Wilson loops as colored triangular paths tracing a face, with the enclosed area shaded.

### Rule 8: Composition

$$\boxed{\text{Diagrams compose by identifying shared vertices and multiplying phase factors.}}$$

Two stella diagrams $\mathcal{D}_1 = (V_1, E_1)$ and $\mathcal{D}_2 = (V_2, E_2)$ compose at a shared vertex set $S = V_1 \cap V_2$ to form $\mathcal{D}_1 \circ_S \mathcal{D}_2 = (V_1 \cup V_2,\; E_1 \cup E_2)$ by:

1. **Vertex identification:** Each shared vertex $v \in S$ appears once in the composed diagram, inheriting edges from both $\mathcal{D}_1$ and $\mathcal{D}_2$.
2. **Phase multiplication:** At each shared vertex, the phase factors of all incident edges (from both diagrams) multiply.
3. **Closure preservation:** If $\mathcal{D}_1$ and $\mathcal{D}_2$ are both closed, then $\mathcal{D}_1 \circ_S \mathcal{D}_2$ is closed.

**Proof of (3):** Since the weight vectors are additive, $\sum_{v \in V_1 \cup V_2} \vec{w}_v = \sum_{V_1} \vec{w}_v + \sum_{V_2 \setminus V_1} \vec{w}_v$. But $\sum_{V_2 \setminus V_1} \vec{w}_v = \sum_{V_2} \vec{w}_v - \sum_{S} \vec{w}_v = \vec{0} - \sum_S \vec{w}_v$. So the composed sum is $-\sum_S \vec{w}_v$. For the composition to be closed, we require that **shared vertices are internal**: the weight flowing into each shared vertex from $\mathcal{D}_1$ is balanced by the weight flowing out to $\mathcal{D}_2$. In practice, this means shared vertices act as junction points where $\vec{w}$ is conserved (analogous to momentum conservation at Feynman diagram vertices).

This is analogous to the composition of Feynman diagrams at internal vertices.

### Rule 9: Phase Accumulation (Winding Number)

$$\boxed{\text{Total phase of a path } P = v_1 \to v_2 \to \cdots \to v_n: \quad \Phi(P) = \frac{2\pi}{3} \sum_{i=1}^{n-1} \Delta c_i}$$

where $\Delta c_i \in \{+1, -1\}$ is the **color step** of edge $i$: $+1$ for a forward step ($R \to G$, $G \to B$, $B \to R$) and $-1$ for a reverse step.

**Source:** Definition 0.1.2 (phase structure).

**Why not use naive phase differences?** The formula $\sum (\phi_{v_{i+1}} - \phi_{v_i})$ is a telescoping sum that always yields zero for closed paths, regardless of the path taken. This fails to capture the winding number. The correct formulation counts **edge-local increments** of $2\pi/3$ per forward step, which tracks the phase as it winds through the branch cut at $\phi = 2\pi \equiv 0$.

**Equivalently**, the phase accumulation can be expressed via the edge phase factor product:

$$\prod_{i=1}^{n-1} \omega^{\Delta c_i} = \omega^{\sum \Delta c_i} = e^{i\Phi(P)}$$

For a closed path ($v_n = v_1$), the total phase is:
- $\Phi = 0 \pmod{2\pi}$ for a color-neutral loop (singlet)
- $\Phi = 2\pi$ for a complete $R \to G \to B \to R$ cycle ($\Delta c = +1$ at each of 3 edges, so $\Phi = 3 \times 2\pi/3 = 2\pi$; one $\lambda$-period, Theorem 0.2.2)
- $\Phi = 2\pi k$ for $k$ complete cycles

## 4. Classification of Physical States

Applying the closure rule (Rule 5), the allowed stella diagrams classify all color-singlet states:

### 4.1 Meson ($q\bar{q}$)

A directed edge from a $T_+$ vertex to its conjugate $T_-$ vertex:

$$\mathcal{D}_\text{meson} = \{v \to \bar{v}\} \quad \text{for any } v \in V_+$$

**Color neutrality check:** $\vec{w}_v + \vec{w}_{\bar{v}} = \vec{w}_v + (-\vec{w}_v) = \vec{0}$. ✅

**Example:** $R \to \bar{R}$ represents a $q_R\bar{q}_{\bar{R}}$ meson.

### 4.2 Baryon ($qqq$)

Three edges from all three $T_+$ vertices converging at a singlet junction point:

$$\mathcal{D}_\text{baryon} = \{R \to \mathbf{1},\; G \to \mathbf{1},\; B \to \mathbf{1}\}$$

**Color neutrality check:** $\vec{w}_R + \vec{w}_G + \vec{w}_B = \vec{0}$ (tracelessness of SU(3)). ✅

**Phase check:** $\omega^0 + \omega^1 + \omega^2 = 1 + e^{2\pi i/3} + e^{4\pi i/3} = 0$. ✅

**Antisymmetry note:** The closure rule identifies the singlet in $\mathbf{3} \otimes \mathbf{3} \otimes \mathbf{3} = \mathbf{1} \oplus \mathbf{8} \oplus \mathbf{8} \oplus \mathbf{10}$ but does not by itself distinguish the totally antisymmetric singlet ($\epsilon_{RGB}$) from other channels. For the minimal baryon diagram (exactly one of each color), the singlet is unique and automatically antisymmetric. For multi-quark states, the $\epsilon$-tensor structure must be imposed as an additional constraint beyond the diagram rules.

### 4.3 Anti-baryon ($\bar{q}\bar{q}\bar{q}$)

The conjugate of the baryon diagram, with three $T_-$ vertices converging:

$$\mathcal{D}_{\bar{\text{baryon}}} = \{\bar{R} \to \mathbf{1},\; \bar{G} \to \mathbf{1},\; \bar{B} \to \mathbf{1}\}$$

This is the image of $\mathcal{D}_\text{baryon}$ under $\mathcal{I}$ (Rule 4).

### 4.4 Color Cycle (Internal Dynamics)

The closed cycle $R \to G \to B \to R$ represents one period of phase-locked oscillation:

$$\mathcal{D}_\text{cycle} = \{R \xrightarrow{\omega} G \xrightarrow{\omega} B \xrightarrow{\omega} R\}$$

**Phase accumulation (Rule 9):** Each edge is a forward step ($\Delta c = +1$), so $\Phi = \frac{2\pi}{3}(1+1+1) = 2\pi$ (one full $\lambda$-period). ✅

**Physical interpretation:** This diagram does not represent an external particle state — it represents the *internal dynamics* of the color field oscillation (Theorem 2.2.1). One complete cycle corresponds to one unit of emergent internal time (Theorem 0.2.2).

### 4.5 Forbidden States (Examples)

| Diagram | Net weight | Status |
|---------|-----------|--------|
| $R \to G$ (open) | $\vec{w}_G - \vec{w}_R \neq \vec{0}$ | Confined |
| $R$ alone | $\vec{w}_R \neq \vec{0}$ | Confined |
| $R + G$ (no $B$) | $\vec{w}_R + \vec{w}_G \neq \vec{0}$ | Confined |
| $R + \bar{G}$ (wrong pair) | $\vec{w}_R - \vec{w}_G \neq \vec{0}$ | Confined (octet, not singlet) |

## 5. Analogy with Feynman Diagrams

The stella diagram formalism parallels the Feynman diagram calculus:

| Feynman Diagrams | Stella Diagrams | Correspondence |
|-----------------|----------------|----------------|
| External lines (asymptotic states) | Color vertices $v \in V$ | Particles $\leftrightarrow$ color charges |
| Internal lines (propagators) | Directed edges with $\omega^{\Delta c}$ | Virtual exchange $\leftrightarrow$ phase propagation |
| Vertices (interaction points) | Singlet junction points $\mathbf{1}$ | Coupling $\leftrightarrow$ color neutrality |
| Wavy lines (gauge bosons) | Wavy lines (gluons $g_{cc'}$) | Photon/gluon $\leftrightarrow$ adjoint edge |
| Loop integrals | Wilson loop face amplitudes | $\int d^4k \leftrightarrow W(\triangle)$ |
| Conservation laws at vertices | Closure rule (Rule 5) | $\sum p = 0 \leftrightarrow \sum \vec{w} = \vec{0}$ |
| Crossing symmetry | Charge conjugation (Rule 4) | $s \leftrightarrow t$ channel $\leftrightarrow T_+ \leftrightarrow T_-$ |
| CPT invariance | $\mathcal{I}^2 = \mathrm{id}$ | Diagram $\leftrightarrow$ conjugate diagram |

**Key difference:** Feynman diagrams live in continuous momentum space; stella diagrams live on a finite discrete graph. This discreteness reflects the pre-geometric nature of the framework — spacetime has not yet emerged at this level of description.

## 6. Consistency Checks

### 6.1 Dimensional Analysis

Stella diagrams are combinatorial objects (vertices, edges, labels). The phase factors $\omega^k$ are dimensionless complex numbers on the unit circle. The weight vectors $\vec{w}_v$ have dimensions $[0]$ (they label representations). No dimensional inconsistency can arise.

### 6.2 SU(3) Representation Theory

The closure rule (Rule 5) is equivalent to the standard SU(3) singlet condition. The tensor product decompositions are:

- **Meson:** $\mathbf{3} \otimes \bar{\mathbf{3}} = \mathbf{1} \oplus \mathbf{8}$ — the singlet component corresponds to the closed $v \to \bar{v}$ diagram.
- **Baryon:** $\mathbf{3} \otimes \mathbf{3} \otimes \mathbf{3} = \mathbf{1} \oplus \mathbf{8} \oplus \mathbf{8} \oplus \mathbf{10}$ — the totally antisymmetric singlet corresponds to $\epsilon_{RGB}$.
- **Wrong pairs** (e.g., $R + \bar{G}$): These live in the $\mathbf{8}$ of $\mathbf{3} \otimes \bar{\mathbf{3}}$, not the $\mathbf{1}$. The closure rule correctly excludes them.

### 6.3 Combinatorial Invariants of the Diagram Graph

The diagram graph has $V = 6$ color vertices, $E = 9$ edges, and $F = 2$ triangular faces (one per tetrahedron). As a CW-complex:

$$\chi = V - E + F = 6 - 9 + 2 = -1$$

**Interpretation:** This is a combinatorial invariant of the diagram 2-complex, **not** the Euler characteristic of $\partial\mathcal{S}$ (which is $\chi = 4$ for the two disjoint $S^2$ boundaries). As a 1-complex (graph only, ignoring faces), $\chi_{\text{graph}} = V - E = -3$, indicating $E - V + 1 = 4$ independent cycles in the connected graph. The two filled triangular faces account for 2 of these cycles; the remaining 2 independent cycles involve cross edges and are topologically non-trivial (they link $T_+$ to $T_-$).

### 6.4 Phase Cancellation at Center

From Theorem 0.2.1, the total field at the center of the stella vanishes by phase cancellation:

$$\chi_\text{total}(0) = a_0 P_0 (e^{i \cdot 0} + e^{i \cdot 2\pi/3} + e^{i \cdot 4\pi/3}) = a_0 P_0 (\omega^0 + \omega^1 + \omega^2) = 0$$

This is precisely the baryon closure condition (§4.2), confirming that the center of the stella corresponds to the color-singlet junction point in stella diagrams.

### 6.5 Chirality Consistency

**Note:** This consistency check involves Phase 2 content (Theorem 2.2.4), consistent with Rule 3's provisional status.

Theorem 2.2.4 (Phase 2) derives the sign of the Sakaguchi-Kuramoto coupling $\alpha = +2\pi/3$ from the net positive topological charge $\langle Q \rangle > 0$. In stella diagrams, this corresponds to the forward orientation $R \to G \to B$ being dynamically preferred over $R \to B \to G$. The chirality convention (Rule 3) is consistent with the limit cycle direction established in Theorem 2.2.2.

## 7. Relation to Wilson Loops and Confinement

The Wilson loop (Rule 7) provides the dynamical content that the closure rule (Rule 5) lacks. While Rule 5 identifies *which* diagrams are color-neutral (kinematics), the Wilson loop area law quantifies the *energy cost* of separating color charges (dynamics):

$$\langle W(C) \rangle \sim \exp(-\sigma \cdot A(C))$$

For a rectangular loop of spatial extent $R$ and temporal extent $T$:

$$\langle W(R, T) \rangle \sim \exp(-\sigma R T) \implies V(R) = \sigma R$$

This linear potential is the dynamical enforcement of confinement. In stella diagrams, this means:
- **Small loops** (confined to a single face $\triangle$): Low action, high probability.
- **Large loops** (spanning multiple faces or crossing $T_+ \leftrightarrow T_-$): Exponentially suppressed.

The string tension $\sigma = (\hbar c / R_\text{stella})^2$ is derived in Proposition 0.0.17j, giving:

$$\sqrt{\sigma} = \frac{\hbar c}{R_\text{stella}} = 440 \text{ MeV} \quad (R_\text{stella} = 0.44847 \text{ fm})$$

## 8. Open Questions

1. **Scattering amplitudes:** Can stella diagrams be extended to compute scattering amplitudes (Phase 6)? This would require defining propagators with momentum dependence and integration rules.

2. **Higher representations:** The current formalism covers $\mathbf{3}$, $\bar{\mathbf{3}}$, and $\mathbf{8}$. Extension to higher SU(3) representations (e.g., $\mathbf{10}$ for the decuplet) would require additional diagram elements.

3. **Multi-stella diagrams:** The FCC lattice (Theorem 0.0.6) tiles space with stellae. Diagrams spanning multiple stellae would describe inter-hadron interactions and could connect to the transfer matrix formalism (Proposition 2.5.2c).

4. **Quantitative Feynman rules:** The current rules are qualitative (which diagrams are allowed, what phases they carry). Assigning quantitative amplitudes to each diagram element — analogous to the Feynman rule $ig\gamma^\mu T^a$ for a QCD vertex — would make the formalism calculational.

---

## 9. Summary

The stella diagram rules provide a complete diagrammatic language for color interactions on $\partial\mathcal{S}$:

| Rule | Content | Source |
|------|---------|--------|
| 1. Color vertex | 6 vertices with weight vectors and phases | Def 0.1.2, Thm 1.1.1 |
| 2. Directed edge | Phase factor $\omega^{\Delta c}$ per edge | Def 0.1.2 |
| 3. Chirality | $R \to G \to B$ preferred direction | Thm 2.2.4 |
| 4. Conjugation | $\mathcal{I}: v \mapsto \bar{v}$ (point reflection) | Thm 1.1.2 |
| 5. Closure | $\sum_{V_\text{state}} \vec{w}_v = \vec{0}$ for physical states | Thm 1.1.3 |
| 6. Gluon line | Wavy adjoint propagator $g_{cc'}$ | Thm 1.1.1 |
| 7. Wilson loop | Face amplitude $W(\triangle) \sim e^{-\sigma A}$ | Prop 2.5.2a |
| 8. Composition | Identify shared vertices, multiply phases | Thm 0.2.1 |
| 9. Phase accumulation | $\Phi(P) = \frac{2\pi}{3}\sum \Delta c_i$ (winding number) | Def 0.1.2 |

These rules classify all physical states (mesons, baryons, anti-baryons), encode confinement as a topological selection rule, and connect to the dynamical content of the framework through Wilson loops and chirality selection.
